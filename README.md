# 立体车库原理演示（Python 3D）

用 Panda3D 做的 6 种立体车库 3D 交互演示（独立窗口，不需要浏览器），供自学和教学使用：每一步存/取车动作都配有"为什么这样动"的讲解。

| 类型 | 规模 | 教学重点 |
|---|---|---|
| 简易升降 | 2 层 × 2 列 | 下层有车，上层的车就取不出来 |
| 升降横移 | 3 层 × 3 列 | 每层留一个空位，靠横移让出下降通道 |
| 垂直循环 | 10 个吊篮 | 比较顺/逆时针哪边近；所有吊篮一起转 |
| 巷道堆垛 | 2 排 × 4 列 × 3 层 | 行走和升降同时进行，耗时取两者的较大值；空板管理 |
| 垂直升降（塔库） | 8 层 | 单台电梯是瓶颈；载车板式要先取空板 |
| 平面移动 | 3 层 × 2 排 × 4 列 | 升降机和台车分工、预定位；夹轮式不需要载车板 |

## 运行

### Windows 一键启动

双击仓库根目录的 `start.bat`。

- 第一次运行会在仓库旁建一个 `.venv` 虚拟环境并安装依赖（需要联网），之后再双击就直接启动。
- 前提是装了 Python 3.8 以上（python.org 版安装时勾选 "Add python.exe to PATH"，或者装了 `py` 启动器）。
- 黑色命令行窗口会和演示窗口一起开着；关掉演示窗口程序就退出。
- 出问题想重装依赖：删掉 `.venv` 文件夹再双击。

### 手动运行

```bash
pip install -r requirements.txt
python main.py
```

运行后会打开一个独立窗口。鼠标左键或右键拖动旋转视角，滚轮缩放，中键拖动平移。空格暂停/继续，N 键执行下一步。

顶部"模式"有两种：

- **司机视角**（默认）：你是来停车的司机，只和右边的出入口终端打交道。点"我要存车"后，车开到入口、识别车牌，确认后系统自动分配车位（3D 里用黄框标出），设备先准备好，再提示你把车开进交接区，最后给出存车凭证。取车时选自己的车牌（相当于刷卡），等车送到出口后上车驶离。只有"开进去""开出来"这两步要你点按钮，其余都是设备自动完成，终端上有进度条和剩余时间。
- **原理演示**：直接点车位按钮存取，可以开单步模式逐步讲解，也可以做 6 种车库的对比。

原理演示模式下：

- 顶部下拉菜单切换车库类型
- 右侧车位按钮（绿色 ● 表示有车）：有车就取，没车就存到这里
- "自动选位存车"：把每个空位都试算一遍，选模拟耗时最短的
- "单步模式" + "下一步"：每个动作都要手动确认，方便讲解
- "对比 6 种车库"：每种随机存取 200 次，列出容量、占地和平均耗时

> 设备速度和占地都是示意值，只适合看趋势，不代表真实产品。

## 代码结构

```
main.py              界面（Panda3D 窗口和控件）与主循环
engine/motion.py     动作原语（平移、转动、沿闭合路径运动）的纯数学部分
engine/scene.py      Panda3D 绘制和动画播放（坐标换算也在这里）
engine/fonts.py      中文字体查找、中文折行
engine/kiosk.py      司机视角的出入口终端（只管画，流程在 main.py 的 driver_park / driver_pick）
garages/*.py         每个文件对应一种车库：调度逻辑 + 外形（不依赖 Panda3D）
tests/               随机存取测试：检查不变量，并核对动画终点和逻辑位置是否一致；渲染层坐标换算测试
DESIGN.md            设计方案
LOGIC.md             五种车库的存取流程（文字版）
```

调度逻辑和 3D 绘制是分开的。如果想读懂某种车库的原理，直接看 `garages/` 下对应的文件就行。

测试：`python -m tests.test_garages`（调度逻辑，不需要 Panda3D）和 `python -m tests.test_scene`（坐标换算和折行，需要装 Panda3D，但不开窗口）
